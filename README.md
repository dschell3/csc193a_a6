# CSC 193A – Encrypt-It!

A page that turns a message into a shift cipher with JavaScript.

## Files

- `encrypt-it.html` – page with the input box, cipher options, and result area
- `encrypt-it.js` – event handlers and the shift cipher
- `style.css` – provided starter styles

## Controls

- **Encrypt It!** – shifts every letter ahead by one (z wraps to a) and shows the result
- **Reset** – clears the input and the result

## Running

Open `encrypt-it.html` in a browser. No build step or server needed.
